# JALGAON VI

A 3D open-world browser game set in Jalgaon, Maharashtra. Start at Golani Market, drive autos and tractors, deliver Bhaiyyaji kulfi and nalyache bhaje, race the Ring Road, dodge cows and potholes, and catch the express at Jalgaon Junction.

**Play:** https://joynicolas.github.io/jalgaon-gta-vi/

- Single file (`index.html`), Three.js built in, no server needed
- Nothing is saved. Close the tab and everything resets
- Controls: WASD move/drive, Shift sprint, Mouse or arrow keys camera, E enter/exit, R radio, M map, P pause

To play your own Khandeshi songs on the radio, add mp3 files and list them in `CUSTOM_TRACKS` near the top of the script in `index.html`.

*Fan-made parody and love letter to Jalgaon. Not affiliated with or endorsed by Rockstar Games or Take-Two Interactive. All characters, music and places are original or generic.*
